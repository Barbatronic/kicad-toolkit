# Fichiers sources externes

Petits fichiers KiCad récupérés depuis d'anciens dépôts, dont la version locale
sur le disque avait été perdue ou modifiée entre-temps. Conservés ici tels
quels pour que `collect_symbols_footprints.py` puisse reconstruire le toolkit
sans dépendre de ces anciens dépôts.
